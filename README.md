# VideoDownloader
GUI VideoDownloader.

1click download.

Get video use yt-dlp and ffmpeg.

support:macOS



# Usage

Get cookies from browser(chrome).
Please login YouTube on Chrome.

Copy Video URL.

Click PASTE button.

Video dwonloading start.
Save file in the Downloads/YouTubeDownloads
