# VideoDownloader
Get video use yt-dlp and ffmpeg.
support:macOS



# Usage

Put "cookies.txt" file in your User Downloads directory.(chrome extension:"get cookie text")

Copy Video URL.

Click PASTE button.

Video dwonloading start.
