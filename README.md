# 🎥 VideoDownloader

![VideoDownloader](https://github.com/user-attachments/assets/f789badd-8b8d-4a9e-8735-c0fb470b7f8b)

**VideoDownloader** is a simple and powerful video downloader for macOS.  
With just one click, you can paste a URL and instantly download videos from platforms like YouTube.  
It leverages `yt-dlp` and `ffmpeg` under the hood to deliver high-quality downloads.

------------------------------------------------------------
![VideoDownloader](https://github.com/user-attachments/assets/f789badd-8b8d-4a9e-8735-c0fb470b7f8b)

## 🚀 Features

- **One-Click Operation**  
  Simply paste a URL and click the download button to start the video download.

- **High-Quality Audio & Video**  
  Uses `yt-dlp` and `ffmpeg` to support various formats and resolutions.

- **macOS Native**  
  Designed to run smoothly on macOS.

------------------------------------------------------------

## 🛠 Installation

### 1. Clone the Repository

   git clone https://github.com/Adolfoi/VideoDownloader.git

### 2. Install Required Tools

Using Homebrew, install the necessary tools by running:

   brew install yt-dlp ffmpeg

### 3. Build and Run the App

1. Open `VideoDownloader.xcodeproj` in Xcode.  
2. Build and run the app by selecting **Product > Run** or pressing ⌘R.

------------------------------------------------------------

## 🎬 How to Use

1. **Copy the Video URL**  
   Copy the URL of the video you want to download.

2. **Launch and Operate the App**  
   - Open the VideoDownloader app.  
   - Click the “PASTE” button to automatically paste the URL from your clipboard.  
   - The download will start, and the video will be saved in a designated folder (e.g., Downloads/YouTubeDownloads).

------------------------------------------------------------

## ⚠️ Notes

- Please use this app in compliance with the terms of service of video platforms such as YouTube.  
- Downloaded videos are intended for personal use only.

# 🎥 VideoDownloader

![VideoDownloader](https://github.com/user-attachments/assets/f789badd-8b8d-4a9e-8735-c0fb470b7f8b)

**VideoDownloader** は、macOS向けのシンプルで高機能な動画ダウンロードアプリです。  
1クリックでURLを貼り付け、YouTubeなどから動画を即座に保存できます。  
内部では `yt-dlp` と `ffmpeg` を使用し、高品質なダウンロードを実現しています。

------------------------------------------------------------
![VideoDownloader](https://github.com/user-attachments/assets/f789badd-8b8d-4a9e-8735-c0fb470b7f8b)

## 🚀 特徴

- **ワンクリック操作**  
  URLを貼り付けてボタンをクリックするだけで動画のダウンロードが開始されます。

- **高画質・高音質**  
  `yt-dlp` と `ffmpeg` を利用して、様々なフォーマットと解像度の動画に対応。

- **macOSネイティブ対応**  
  macOS上で快適に動作するネイティブアプリ。

------------------------------------------------------------

## 🛠 インストール方法

### 1. リポジトリのクローン

   git clone https://github.com/Adolfoi/VideoDownloader.git

### 2. 必要なツールのインストール

Homebrewを使用して、以下のコマンドで必要なツールをインストールします：

   brew install yt-dlp ffmpeg

### 3. アプリのビルドと起動

1. `VideoDownloader.xcodeproj` を Xcode で開きます。  
2. 「Product > Run」または ⌘R を実行してアプリをビルド＆起動します。

------------------------------------------------------------

## 🎬 使い方

1. **動画URLのコピー**  
   ダウンロードしたい動画のURLをコピーします。

2. **アプリの起動と操作**  
   - VideoDownloaderアプリを起動します。  
   - 「PASTE」ボタンをクリックすると、クリップボードのURLが自動的に貼り付けられます。  
   - ダウンロードが開始され、動画は指定のフォルダ（例: Downloads/YouTubeDownloads）に保存されます。
